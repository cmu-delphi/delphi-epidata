# Delphi V5 API

This is the documentation for accessing Delphi's epidemiological data streams via the new V5 API. Interactive, endpoint-level documentation is available on the [Delphi V5 API Landing Page](https://delphi.cmu.edu/epidata/v5/docs).

Many database and query patterns in the legacy API (the [COVIDcast endpoint](covidcast.md)) emerged from the rapid demands of the COVID-19 response. However, this legacy setup introduced critical bottlenecks. To address those limitations, the V5 API improves data quality, speeds up development times, and enhances query performance.

> **Get updates:** Delphi operates a [mailing list](https://lists.andrew.cmu.edu/mailman/listinfo/delphi-covidcast-api) for users of the API. We will use this list to announce changes, corrections to data, and new features. We strongly encourage all users to subscribe.

## Overview of V5 Endpoints

Unlike the COVIDcast endpoints, V5 has three categories of data access under the `/epidata/v5` route prefix:

- `/archive/` fetches the full version history of a source/signal. Each row represents a "diff" (when the value for a specific key changed).
- `/snapshot/` gets the data as it was known on a specific release date.
- `/aux_data/` accesses source-specific auxiliary tables containing metadata, laboratory protocols, or additional static keys (e.g., NWSS wastewater facility descriptions).

Additionally, various metadata routes are available for querying schema columns, active signals, geographic types, and distinct values. See the [V5 Metadata](v5_meta.md) documentation for more details.


## Authentication and Rate Limits

Anyone may access the Epidata API anonymously without providing any personal data. Anonymous API access is currently rate-limited and restricted to public datasets. The rate limits are 60 requests/hour general, with an additional limit of 5 requests/minute on `/archive/` and 3 requests/minute on `/snapshot/`.

You can [register a free API key](https://api.delphi.cmu.edu/epidata/admin/registration_form) to remove these limits. If you regularly or frequently use our system, please consider using an API key even if your usage falls within the anonymous limits. API key usage helps us understand how our tools are used, which informs our future research, data partnerships, and funding.

Endpoints that require an API key are marked with a 🔒 lock icon. You can use the **Authorize** button at the top of the [Delphi V5 API Landing Page](https://delphi.cmu.edu/epidata/v5/docs) to set your key either as an HTTP header or query parameter.

For more information about how we use the data you provide us through your registration and API request activity, see our [Privacy Statement](privacy_statement.md). At any time, you may submit a [Deletion Request](https://api.delphi.cmu.edu/epidata/admin/removal_request) to have us deactivate your key and destroy all information associating that key with your identity.
